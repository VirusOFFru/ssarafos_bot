# SSARAFOS Bot (Python 3.14.5)

Эта версия специально переписана под `python-telegram-bot`, чтобы нормально ставиться на **Python 3.14.5** на Windows без Visual C++ Build Tools и Rust.

## Что умеет
- каталог товаров
- карточка товара
- корзина
- оформление заказа с адресом одним сообщением
- уведомление админу о новом заказе
- админка: просмотр заказов
- админка: добавление товара
- админка: снять товар с продажи / вернуть / удалить
- админка: принять заказ / отменить / добавить трек-номер

## 1. Подготовка `.env`
Скопируй `.env.example` в `.env` и заполни значения:

```env
BOT_TOKEN=твой_токен_от_BotFather
ADMIN_ID=123456789
SUPPORT_USERNAME=ssarafos
DB_PATH=data/shop.db
```

`ADMIN_ID` — это **числовой Telegram ID**, без `@`.

## 2. Установка зависимостей
В терминале PyCharm:

```bash
pip install -r requirements.txt
```

## 3. Запуск

```bash
python bot.py
```

## 4. Использование
- `/start` — старт для покупателя
- `/admin` — панель администратора
- `➕ Добавить товар` — создать товар прямо из Telegram
- `📋 Все заказы` — список последних заказов
- `📦 Управление товарами` — скрыть/вернуть/удалить товар

## Почему эта версия ставится на 3.14.5
Потому что она **не использует старый aiogram-стек**, который тянул проблемные сборки `aiohttp` и `pydantic-core` у тебя на Windows.
